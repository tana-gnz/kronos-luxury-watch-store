# Kronos 

A minimalist and responsive static website for **Kronos**, a luxury mechanical watchmaking store and restoration workshop. This project was created for the Markup Languages course (U.T.2 - Prototype 1 - Delivery 1) using semantic HTML5 and CSS3 (Flexbox and Media Queries) across three device breakpoints (Mobile, Tablet, and Desktop).

## Getting Started

These instructions will give you a copy of the project up and running on your local machine for development, testing, and grading purposes.

### Prerequisites

Requirements for the software and other tools to view, edit, and validate the project:
- [Visual Studio Code](https://code.visualstudio.com/) - Source code editor
- [W3C Offline HTML Validator](https://marketplace.visualstudio.com/) - VS Code plugin used for HTML validation
- Any modern web browser (Google Chrome, Mozilla Firefox, or Microsoft Edge)

### Installing

A step by step series of examples that tell you how to get a development environment running:

1. Clone the repository from the `main` branch to your local machine:

    git clone https://github.com/tana-gnz/kronos-luxury-watch-store

2. Open the project folder in Visual Studio Code:

    cd your-repository-name
    code .

3. Open the `index.html` file directly in your browser (or use the Live Server extension) to view the animated hero banner, the 10-watch responsive gallery, the technical specifications table, and the workshop section.
